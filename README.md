# Proposta de novo site: Atalos

Prévia do redesign completo do site da Atalos Soluções Sustentáveis. **Não é o site oficial.**

- Prévia: https://leandrotanuri.github.io/atalos/
- Home só com formulário: https://leandrotanuri.github.io/atalos/formulario
- Pacote para publicar no servidor da Atalos: [download/atalos-site-producao.zip](download/atalos-site-producao.zip) (instruções no `LEIA-ME-PUBLICACAO.txt` dentro do zip)

## O que tem
- As 24 páginas do site antigo, **com as mesmas URLs** (ex.: `/servicos/gestao-ambiental/cetesb`), para não perder posições no Google.
- Todo o conteúdo e as imagens do site antigo, no visual novo.
- `sitemap.xml`, títulos e descrições para o Google, dados estruturados (empresa, serviços, breadcrumbs, FAQ).
- Formulário com os mesmos campos do site antigo (envia para `enviar-orcamento.php` no servidor da Atalos).
- `.htaccess` para Apache: URLs sem `.html`, redirecionamentos 301 e página 404.

Nesta prévia o formulário não envia e as páginas estão marcadas para não aparecer no Google.
